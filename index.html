## The Problem & The Build

Relying on out-of-the-box alerts wasn't cutting it. I wanted to see exactly how network traffic and endpoint behavior correlated during an attack. I spun up a self-hosted SOC environment, ingesting raw firewall logs (pfSense), IDS alerts (Suricata), and granular Windows event logs using Splunk Universal Forwarders.

# How I hunt for Kerberoasting anomalies (EventCode 4769)

index=windows sourcetype=WinEventLog:Security EventCode=4769 Ticket_Options=0x40810000 Ticket_Encryption_Type=0x17

| stats count min(_time) as firstTime max(_time) as lastTime by src_ip, Target_UserName, Service_Name

| where count > 5

## Results in the Wild

  • Configured Sysmon to watch the things that matter: unexpected process creation, strange file hashing, and registry tampering.
  • Ran a simulated brute-force and Pass-the-Hash attack. The SIEM caught it instantly, triggering automated Slack alerts via Splunk Webhooks before lateral movement could occur.
  • Tied every custom alert back to the MITRE ATT&CK Framework so the team always speaks a unified defensive language.

Serverless Phishing Auto-Triage Pipeline

Platform: Cloudflare Edge Tags: SOAR, V8 Isolates, Automation

## Why I Built It

Traditional incident response pipelines often rely on bloated Node.js backends that suffer from cold starts—every second counts when a user reports a phishing email. I moved this entire triage workflow to the edge using Cloudflare Workers and strict TypeScript, leveraging V8 isolates for near-instant execution.

// Handling payloads at the edge without blocking the main thread

export default {

async fetch(request, env, ctx) {

const data = await request.json();

const urlToScan = extractIOC(data.body);

// Background task: non-blocking Threat Intel check

ctx.waitUntil(scanWithVirusTotal(urlToScan, env.VT_API_KEY));

return new Response("Ingested via Edge", { status: 202 });

}

}

## Architectural Wins

  • Zero Cold Starts: The pipeline triggers the moment a user hits "Report," slashing time-to-quarantine (TTQ) by over 85%.
  • Resource Efficiency: Designed natively around the platform's strict 128MB isolate memory limit by streaming payload data rather than buffering it all into RAM.
  • Secure Tracing: Generated completely non-predictable trace IDs using crypto.randomUUID() to track the lifecycle of the threat across our distributed systems.

Malware Sandbox Analysis

Sometimes you have to let the bomb go off to see how it was built. I structured a highly secure, isolated forensic environment specifically to detonate aggressive malware strains safely.

Using Cuckoo Sandbox, I recorded exactly how variants like WannaCry attempt to modify system registries and replicate. By taking memory snapshots and running them through Volatility, I was able to expose the injected thread IDs hiding inside legitimate processes like svchost.exe, and map their precise Command and Control (C2) network beaconing.

Zero-Trust Network Redesign

"Trust nothing, verify everything." I lead the initiative to deprecate an aging, vulnerable IPSec VPN infrastructure in favor of a modern Zero-Trust approach.

Instead of giving remote workers blanket access to the subnet, I implemented application-layer identity checks. Using Cloudflare Access integrated with Okta MFA, internal apps are completely invisible to the open internet. Access is granted per-request based on strict Role-Based Access Control (RBAC), effectively reducing the external attack surface and completely neutralizing lateral movement risks.
